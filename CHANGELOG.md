# Журнал изменений
## [1.0.0] - 2026-11-18 (Первоначальная версия)
### Добавлено
- Базовая реализация класса `Stack` с методами `push`, `pop`, `size` и внутренним механизмом динамического расширения массива `ensureCapacity`.
- Набор Unit-тестов `StackTest`, проверяющий:
    - Корректность добавления элементов (`push`).
    - Корректность извлечения элементов в обратном порядке (`pop`).
    - Генерацию исключения при извлечении из пустого стека (`popEmpty`).
    - Корректность подсчета размера (`size`, `sizeEmpty`).
    - Отсутствие утечек памяти при работе с большими объектами (`memoryLeak`).

### Выявленные проблемы:
- Тест `memoryLeak` завершается с ошибкой `FAIL: memory leak is detected, stack memory control is incorrect`.
