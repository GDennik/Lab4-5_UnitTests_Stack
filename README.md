## Описание
Данный репозиторий содержит реализацию структуры данных `Stack` на языке Java и набор модульных тестов (`Unit tests`) для проверки её корректности. Особое внимание уделено тестированию на отсутствие утечек памяти (memory leak) при работе со ссылочными типами данных.
___

## Структура проекта

- `src/su/dng/stack/Stack.java` — основная реализация класса Stack.
- `test/su/dng/stack/StackTest.java` — набор unit-тестов с использованием фреймворка JUnit.
___

## Как запустить тесты
Убедитесь, что в проекте подключена библиотека JUnit. 
Запустите класс `StackTest` через вашу IDE или с помощью сборщика проектов:
```bash
# Maven
  mvn test
```
